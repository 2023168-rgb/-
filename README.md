# 토타디 - 3D 타워 디펜스

브라우저에서 실행하는 3D 타워 디펜스 프로토타입입니다.

## 실행 방법
- GitHub Pages를 켜거나, 로컬 웹 서버에서 `index.html`을 실행하세요.
- Three.js는 jsDelivr CDN에서 불러옵니다. 인터넷 연결이 필요합니다.

## 현재 구현
- 3D 맵과 적 이동 경로
- 카메라맨, 스피커맨, TV맨, 타이탄 카메라맨 유닛
- 유닛 뽑기 및 보관함
- 맵 배치, 자동 타겟팅, 투사체, 공격 모션
- 웨이브, 기지 체력, 코인 보상
- 배치 유닛 강화 및 회수
- 마우스 드래그 시점 회전, 휠 확대/축소

## 참고
현재 버전은 싱글 플레이 프로토타입입니다. 협동 모드는 실제 실시간 멀티플레이 서버가 필요해 아직 연결되지 않았습니다.
